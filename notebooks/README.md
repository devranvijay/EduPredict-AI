# EduPredict AI - walkthrough notebook

A self-contained folder: copy it anywhere and it runs on its own.

```
edupredict_walkthrough.ipynb     the notebook (start here)
data/edupredict_synthetic.csv    the dataset: 12,000 rows = 2,000 simulated students x 6 of 8 subjects, 32 columns
edupredict/                      the code the notebook imports
  ann.py                         neural network from scratch in NumPy (forward pass, backpropagation, gradient descent)
  preprocessing.py               loading, encoding, scaling, student-grouped train/validation/test split
  evaluation.py                  MAE, RMSE, R2
  learning_rules.py              McCulloch-Pitts, Hebb's rule, Delta rule
  synthetic_data.py              the dataset generator (deterministic)
requirements.txt                 Python packages
```

## Run

```bash
pip install -r requirements.txt
jupyter notebook edupredict_walkthrough.ipynb      # or open it in VS Code and choose Run All
```

It takes about a minute: the notebook trains three networks (`early`, `during_term`, `late`) that differ in which inputs
are available, evaluates them on students they have never seen, and also shows the classic neuron models.

## What the notebook covers

1. The problem and the dataset (with a column dictionary)
2. Exploration, and a student-grouped train / validation / test split
3. Architecture: inputs, one hidden layer of 16 ReLU neurons, one linear output, mean-squared-error loss
4. Training, one prediction worked out by hand, and a numerical check of backpropagation
5. Learning curves, weight changes, actual vs predicted marks, and test metrics against a baseline
6. McCulloch-Pitts, Hebb's rule and the Delta rule, including the Delta rule on the student data
7. Limitations and next steps

**The data is synthetic**: it was generated by `edupredict/synthetic_data.py`, so it holds relationships chosen by the
generator and no real student records. Results show that the method works, not how real students behave.
