# EduPredict AI - walkthrough notebook

One notebook where everything happens: copy this folder anywhere and run it.

```
EduPredict_AI.ipynb              the notebook - all the code is in its cells (start here)
data/edupredict_synthetic.csv    the dataset: 12,000 rows = 2,000 simulated students x 6 of 8 subjects, 32 columns
requirements.txt                 Python packages
```

The notebook imports nothing from other files. The dataset file is optional: if `data/edupredict_synthetic.csv` is missing,
the notebook generates it (the generator is in its first sections, and is deterministic). So the single `.ipynb` file also works on its own.

## Run

```bash
pip install -r requirements.txt
jupyter notebook EduPredict_AI.ipynb      # or open it in VS Code and choose Run All
```

It takes under a minute: the notebook trains three networks (`early`, `during_term`, `late`) that differ in which inputs
are available, and evaluates them on students they have never seen. The outputs are already saved in the file, so it can also just be read.

## What the notebook covers

1. The dataset, with a column dictionary, and the code that generates it
2. Exploration, preprocessing, and a student-grouped train / validation / test split
3. The neural network written in NumPy: forward pass, backpropagation, gradient descent (one hidden layer of 16 ReLU neurons, linear output, mean-squared-error loss)
4. Training, one prediction worked out by hand, a numerical check of backpropagation, learning curves and weight changes
5. Actual vs predicted marks, test metrics against a baseline, one student across all subjects
6. McCulloch-Pitts, Hebb's rule and the Delta rule, including the Delta rule on the student data
7. A hidden-layer size check, limitations and next steps

**The data is synthetic**: it is generated by code in the notebook, so it holds relationships chosen by the generator and no
real student records. Results show that the method works, not how real students behave.
