# EduPredict AI: Student Academic Performance Prediction Using a NumPy-Based Artificial Neural Network

## 1. Problem statement

Can an ANN learn relationships between student academic indicators and final marks, and how accurately
can it predict marks for previously unseen students? The model estimates marks from patterns in its
training data; it cannot guarantee a student's future result or show that changing one input causes a
change in marks.

## 2. Dataset (synthetic)

The dataset is **simulated**, generated by `src/synthetic_data.py` (seed 2026); full column dictionary and
generating rules are in `docs/synthetic_dataset.md`. It replaced an earlier version of the project that used
the UCI *Student Performance* data, which lacks attendance and assignment information.

- 2,000 simulated students × 6 subjects (Mathematics and English for all, plus 4 of Physics, Chemistry, Biology, Computer Science, History, Economics) = 12,000 rows, 32 columns, no missing values.
- Factors: home (parent education, income band, internet, commute), lifestyle (part-time job, extracurricular hours, sleep, stress, health, tutoring, past failures), subject context (interest, class size), last year's score, term activity (study hours, attendance, assignment completion, late submissions, assignment and quiz scores, participation) and the mid-term.
- Target: `final_marks` = 0.6·final exam + 0.2·mid-term + 0.2·assignment average (0–100). Mean 62.0, SD 15.9, pass rate (≥ 40) 91.8%.
- **Because the data is simulated, the model can only recover relationships the generator contains.** Accuracy here says the pipeline works; it is not evidence about real students.

## 3. Method

1. **Split:** 70/15/15 by student → 8,400 train / 1,800 validation / 1,800 test rows (1,400 / 300 / 300 students), seed 42. The test set is evaluated once, after all choices are made.
2. **Preprocessing:** numeric features standardised, binary 0/1, `subject` one-hot; statistics from the training split only. `final_exam_score`, `grade_letter` and `passed` are never inputs.
3. **Three models by when information is available:** `early` (25 inputs: home, lifestyle, subject, last year's score), `during_term` (31: adds attendance, study hours, assignments, quizzes, participation), `late` (33: adds mid-term and assignment averages — components of the target).
4. **ANN:** inputs → 16 ReLU neurons → 1 linear neuron; MSE loss; backpropagation; mini-batch gradient descent (lr 0.01, batch 128, ≤ 300 epochs); early stopping on validation loss. All in NumPy (`src/ann.py`).
5. **Verification:** backprop gradients match numerical gradients (max relative error 7.1e-8 / 1.9e-8 / 1.3e-7). 12 unit tests pass.
6. **Baseline:** predict the training-set mean for every row.
7. **Fundamentals lab:** McCulloch–Pitts neuron (AND, OR), Hebb's rule (bipolar AND) and Delta rule (learning AND) as toy examples in `src/learning_rules.py`, plus a **Delta-rule neuron trained on the student data**: one linear neuron, updated one student at a time on the training split, compared on unseen rows with the closed-form best straight line and with the 16-neuron network (dashboard: ANN fundamentals lab → On the student data). Backpropagation generalises error-driven learning to hidden layers through the chain rule; it is not the same as the single-neuron Delta rule.

## 4. Results (marks on 0–100)

| Model | Split | MAE | RMSE | R² |
|---|---|---|---|---|
| Baseline (mean) | test | 13.13 | 16.52 | 0.00 |
| ANN `early` | train / val / **test** | 6.37 / 6.53 / **6.64** | 7.93 / 8.19 / **8.36** | 0.74 / 0.74 / **0.74** |
| ANN `during_term` | train / val / **test** | 4.79 / 4.85 / **4.99** | 6.00 / 6.10 / **6.26** | 0.85 / 0.86 / **0.86** |
| ANN `late` | train / val / **test** | 2.90 / 2.95 / **3.01** | 3.61 / 3.75 / **3.77** | 0.95 / 0.95 / **0.95** |

(Plots: `results/training_overview.png`; the dashboard's Results tab shows loss curves, actual-vs-predicted and the per-row test table.)

**Observations**

- Every added group of information lowers test RMSE: 16.52 (baseline) → 8.36 → 6.26 → 3.77.
- Train, validation and test errors are close in all three models, so there is no sign of overfitting.
- Permutation importance on the test rows (RMSE increase when one input is shuffled; dashboard Results tab) shows what each model relies on: `early` → `prev_year_score` (+10.4 marks) far ahead of `subject_interest` (+1.7) and `stress_level` (+0.6); `during_term` → `quiz_avg_score` (+5.4) and `prev_year_score` (+5.2), with attendance only +0.3 because correlated inputs share credit; `late` → `assignment_avg_score` (+5.9) and `midterm_score` (+5.3). This is a shuffling test, not a retrain-without-the-input ablation, and on synthetic data it mirrors the generator.
- The `late` model's R² of 0.95 is partly structural: mid-term and assignment average make up 40% of `final_marks` by construction. It reached the 300-epoch cap before early stopping triggered, so it may be slightly under-trained.
- **Is 16 hidden neurons needed? No evidence for it.** Validation RMSE for 2/4/8/16/32 neurons was 8.11/8.14/8.14/8.19/8.20 (`early`), 6.07/6.09/6.09/6.10/6.18 (`during_term`) and 3.65/3.66/3.70/3.75/3.76 (`late`). Two neurons did as well as 32, which suggests the simulated target is close to a linear function of the inputs (it is built mostly from additive terms). The Delta-rule experiment confirms this: a single linear neuron, with the best possible straight-line weights fitted on all 19 numeric `during_term` inputs, reaches a test RMSE of 6.28 against 6.26 for the 16-neuron network, which also sees the binary inputs and the subject. On this synthetic data the hidden layer therefore adds no measurable accuracy over a linear fit (a single run, so a gap this small is not meaningful either way). With only three inputs (attendance, quiz, study hours) the Delta-rule neuron reaches 8.05 (best straight line 7.78), and with `prev_year_score` alone 9.63 (9.56). We kept 16 as the specified starting configuration and make no claim that it is best.

## 6. Limitations

- **Synthetic data:** relationships are assumptions I wrote, plausible but not measured on real students. The model re-discovers what was put in; do not generalise to real populations.
- Simulated data is smoother than real data (no dropouts, cheating, exam-day effects, measurement error in attendance or study hours).
- Single split and seed; no confidence intervals or cross-validation.
- `late` includes components of the target, so its accuracy is partly built in.
- Correlation, not causation: the what-if explorer shows model behaviour, not the effect of an intervention. Several inputs (e.g. `gender`, `internet_access`, `class_size`) have no effect on marks by construction.
- Hidden-layer size and learning rate were checked only lightly (single runs). The straight-line comparison uses the 19 numeric inputs only, so it is not exactly the same input set as the network's 31.
- The Delta-rule neuron learns online with a fixed learning rate, so with a large rate it keeps bouncing around the best straight line instead of settling (seen in the dashboard).
- Output is not bounded; the dashboard clips display to 0–100.
- Any real deployment would involve sensitive attributes and decisions about individuals; this is an educational demonstration.

## 7. Reproducibility

`python -m src.synthetic_data` then `python train.py` regenerates the data, models and results (seeds fixed).
`python -m pytest` runs the tests.
